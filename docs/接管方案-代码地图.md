## 3. 三条主链路（接管时最该先看懂的）

**启动链**：`MainActivity` 开关 → `PetService.start`（`PetService.kt:57-71`）→ `onCreate`（`:108-136`，取 `wm` `:122`、`goForeground` `:131`）→ `onStartCommand`（`:138`）→ `spawnAll`（`:228`）→ 每只 `Pet(...)` 注册 6 个回调（`:285-289`）→ `w.addView`（`:309`）→ `pet.start()`（`:311`）→ 进随机链（`Pet.kt:585`）。

**动画调度链**：`Pet.start` → `scheduleNext`（`Pet.kt:367`）→ 掷权重 → `playIdle / playTurn / playMove / playRandomAction` → `play(slug)`（`Pet.kt:302`）→ IO 线程解码 WebP（`:309-317`）→ 主线程换 `current` 并 `start()`（`:323-330`）→ 帧回调 `invalidateDrawable`（`:656`）→ `onDraw` 画帧（`:634`）→ 到时 `onEnd` → 回 `scheduleNext`。

**对话链**：`tickSpeech`（`PetService.kt:547`）/ 点击 / 长按菜单 → `sayFrom(category)`（`:491`）→ 冷却与开关判定 → `Lines.pick`（`Lines.kt:44`）→ `say(pet, text)`（`PetService.kt:371`）→ 量尺寸（`:406`）→ 建气泡窗口（`:413`）→ `followBubble`（`:459`）跟到头顶 → 3.6 秒后 `dismissBubble`（`:477`）。

## 6. 冻结区与红线

- `refs/` 是上游只读快照（`MAKE-YOUR-OWN-PET.md`、提示词库、抠像脚本），**只在读素材链时引用，不做任何修改**；它在 `git status` 里显示为未跟踪目录，是接管前就存在的状态。
- `app/src/main/assets/webp/` 不入库（`.gitignore`），由 `tools/fetch-and-transcode.*` 生成；新环境先跑还原脚本再构建。
- 素材来源与许可见 `NOTICE.md:12-23`：动画来自 `PC2005-cloud/dsh-pet`，**允许开源使用、禁止商用**；原始素材不在仓库内。接管的商业用途评估必须单独立项，本文不代替该结论。
- 代码本体 MIT（`NOTICE.md:5-8`），`Physics.kt` 是上游 `src/shared/physics.ts` 的逐行移植，改动它等于偏离上游基线，接管期间保持原样。
